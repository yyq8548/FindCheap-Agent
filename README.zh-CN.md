FindCheap Agent 是一个 Codex 购物研究插件，支持商品搜索、商品匹配、价格查询、商品卡片、证据驱动对比视图、已验证优惠和购物监控。检索只读；报价和 Watch 有独立授权边界。每次最多返回 8 个商品，分为三层：最多 2 个官网结果、3 个可信或高评分匹配、3 个高性价比高匹配结果。

Codex 通过本地 stdio MCP 的 `search_products` 开始文字检索，图片、比较和后续操作使用各自工具。符合条件的 Awin、Shopify、已配置 eBay／WooCommerce 和官网来源可以并行查询；合格推荐不足时执行受限互补检索，卡片上限不是填满指标。公开网页补搜必须取得服务端恢复资格及宿主授权，不是只要结果为空就自动执行。

产品权限不包括下单、结账、付款或预留库存。匿名购物车报价有独立的授权与副作用要求，目标规则及待核验项见 Agent 总设计。

## 使用方法

在 Codex 中直接调用 FindCheap Agent：

```text
@FindCheap Agent 搜索 Sony WH-1000XM6，显示商品卡片。
```

启用插件后，也可以直接用自然语言提问：

```text
帮我找三个可信商家的 AirPods Pro 2 报价。
```

也可以对同一次结果中的 2–4 张商品卡进行并排对比：

```text
把前面三个商品放在一起对比。
```

也可以附上商品照片或截图进行视觉搜索：

```text
帮我找图中同款，再给我高度相似和同风格的选项。
```

需要查询运费、税费和预估总价时，请提供美国邮编：

```text
报价第一个商品，美国邮编是 33065。
```

创建购物监控：

```text
监控这个商品，全新价格低于 $170 时提醒我。
```

询问已选商品现在是否值得购买：

```text
这个现在值得买吗，还是应该等一等？
```

后续报价时，可以用结果序号或直接选择商品卡片。FindCheap Agent 会复用首次结果中的商品和变体，不会重新按标题搜索。活跃选择两小时过期，活跃缓存最多保存最近 128 份搜索快照。受支持的持久化可在同一可信任务内恢复历史，但不刷新价格或库存，也不恢复过期报价及授权；桌面重启和 UI 交互仍单独验收。

## 商品搜索

插件通过一次受约束的请求并行查询符合能力、市场和配置条件的 Awin、Shopify、eBay、WooCommerce 和已知官网来源。来源检索词可以不同，但保留身份锚点；最终候选仍须核验原品类、规格、预算及必需功能。中文商品词转换为来源适用的搜索词，品牌、型号、SKU、GTIN、颜色、尺寸和容量不会因此改写。

咖啡形态与机器兼容性分别核验。澄清为胶囊咖啡时保留原目标和其他要求，排除器具及冲突形态；机器系统未知时先询问，不设综合首选。在既有两轮预算内，Shopify 有游标时读取新一页，回执区分实际读取的页和商家与估算总量。Woo 单店不支持或局部预算耗尽，不阻止仍符合条件的独立来源恢复。

实际读取受支持的 Shopify 官网商品链接后，搜索和后续操作保留原商品路径及选定变体。同店其他商品、套装或变体不能只凭标题相似入选；Shopify 自有变体 ID 与所选链接矛盾时拒绝该候选。跨店同款需要共同 GTIN，或相同品牌与 MPN，并核对已选属性；不同商家的本地 ID 不互相比对。

继续搜索会保留原 URL 身份；纠正或更换商品时释放旧身份，其他要求按原目标合并规则处理。只有明确允许时才展示带标签的替代研究候选，不能把它们当成原商品。对已确认跨店同款显式换规格，检查必须从实际选中商家和父商品返回唯一、符合所选属性的变体；检查替代品不能悄悄替换原目标。

Shopify 和 WooCommerce 身份锚点属于服务端私有状态，不能由模型作为搜索参数提交。Woo 快照会核对并保存原商家、商品、选定变体与 URL 绑定；无锚点旧快照仍兼容，其他任务不能读取。双 MCP 服务实例的恢复合同已验证，最终安装包的原生验收仍待完成。详见 [URL 身份与快照恢复记录](docs/engineering/changes/2026-09-09-shopify-url-identity-followup.md)。

用户明确提出的非价格要求会作为硬性筛选条件，而不是仅用于排序。匹配器会统一处理屏幕尺寸、内存、存储、包装数量、容积、重量、分辨率、刷新率、功率、服装和鞋码、颜色、型号代际及兼容性表达。它支持常见公制、美制和中文写法，可以将 `14 英寸`、`35.56 厘米` 和 `14寸` 等同类表达正确对应，也能识别至少、最多和约等范围要求。内存、存储、物理尺寸、数量和营销刷新率标签会分开判断，避免因为数字相同而产生错误匹配。

用户搜索主体商品时，保护套、扩展坞、支架、屏幕保护膜和替换耳罩等常见配件会被排除；明确搜索配件时仍可正常返回。型号和代际按照完整边界匹配，较长型号不会被误认为用户要求的较短型号。

`MacBook Pro` 这类明确的产品系列可以作为品类判断中的身份依据。查询已经包含产品系列或型号时，翻译不会再追加 `laptop`、`phone`、`headphones` 等通用品类词。商品标题即使没有这些通用词，也不会因此被误删。用户没有说明成色时，路由器不会假设商品是全新。每项结果会保留实际观察到的成色标签，`UNKNOWN` 仍可进入候选。用户明确要求全新、二手、翻新、开箱或成色未知时，该要求才会成为筛选条件。

搜索结果使用三种匹配标签：

- `EXACT`：请求的变体具有可靠的 UPID、GTIN，或品牌加 MPN/SKU 证据。
- `DISCOVERY_MATCH`：结果与请求相关，但证据不足以确认是同一商品。
- `SIMILAR`：相似选项，不是同一商品。

### 视觉商品搜索

用户附上商品图片或截图后，Codex 会把直接观察与低置信度推断分开记录。商品品类以及用户明确提供的品牌/型号保留为硬条件；从像素推断的领型、饰边、蝴蝶结、材质、接缝位置和版型只参与排序，除非用户明确要求。`search_visual_candidates` 最多返回 6 张安全加载的候选图供 Codex 复核。第一批候选若全部存在可见冲突，FindCheap 会自动执行一次更宽的元数据搜索，并可返回最后一批候选进行第二次复核；禁止第三轮。文字搜索仍只调用一次 `search_products`；Watch 和批量任务不执行图片重排。

最终确认工具只接受同一个不可变视觉快照中的候选 ID；快照 10 分钟过期且只能使用一次。有冲突的候选直接排除；`POSSIBLE_SAME_ITEM` 至少需要 3 个不同匹配属性，`HIGHLY_SIMILAR` 至少需要 2 个。更弱证据降为 `SAME_STYLE`，除非用户明确要相似替代，否则不展示。该流程直接复用当前 Codex，不需要部署外部视觉模型，也不需要视觉服务凭据。

视觉相似不等于精确身份。除非稳定型号、款号、SKU 或 GTIN 能独立确认身份，否则视觉结果只能保持为 `DISCOVERY_MATCH` 或 `SIMILAR`，不会伪装成 `EXACT`。图片缺少一个影响决策的关键信息时，Agent 最多只追问一次商品类型、尺寸、预算、颜色或使用场景。匹配器包含 30 个视觉属性 Golden Tasks，并设置了不低于 95% 的分组门槛；真实截图的人工 Top-3 相关性仍属于发布评测指标，不会被当作自动身份确认。

### 结果可靠性

FindCheap Agent 分开表达商品身份、商家可信度、成色和价格证据：

- 匹配标签只描述商品身份。`EXACT` 需要可靠的身份信息；`DISCOVERY_MATCH` 和 `SIMILAR` 都不能证明两个商品页属于同一商品。
- 搜索结果分成三组：请求品牌的已验证官网匹配最多 2 项，可信或合格高评分商品最多 3 项，具备可比价格或已确认优惠优势的可信匹配最多 3 项。商品评分高于 `3.8/5` 且至少有 `2` 条评价，可以让匹配商品进入第二组，但不验证商家、不授予综合首选、性价比或报价资格。其他待核验候选单列为研究线索。标记为 `RISKY` 的域名直接排除。
- 已批准的 Awin 商家可以进入可信匹配组；佣金不会改变商品相关性评分。
- 卡片中的商品价是数据源在观察时返回的价格。运费、税费、必要费用、会员价、优惠券和到手总价，只有取得对应商家证据或报价成功后才会显示。按 ZIP 计算的税费可能是预估值，最终金额以商家结账页为准。
- `UNKNOWN` 表示数据源没有验证商品成色，不能描述为全新。对于可信证据有限的商家，购买前应检查卖家身份、退货政策和付款保障。

联盟佣金不会影响相关性评分。普通发现以最多三个可推荐结果为检索目标，不为填满八张卡继续请求；显式同款比较仍保留必要覆盖。受限补搜重新核验原要求。只有服务端返回 `REQUEST_WEB_SEARCH` 才能申请 Chrome 授权；已分类的暂时来源故障可以允许独立恢复，输入、响应结构校验、安全错误和总预算耗尽不能被绕过。

## 报价比较与配送估算

只有当身份信息证明结果属于同一商品和同一变体时，插件才会比较报价。精确匹配排在探索结果和相似选项之前。

`compare_selected_products` 使用同一个有效搜索快照中的稳定 `selectionId`，生成真正的 2–4 列对比视图。服务器负责判断这些结果属于已验证同款报价，还是不同商品选择；所有商品事实、未知值、限制、统一价格口径、价差和推荐结果也由服务器生成。模型不能提交商品事实、优缺点、价格或推荐商品 ID。一次价格比较不会混用商品价与到手价。

每个结果可以包含：

- 商家和商品名称
- 已验证的公开商品价
- 图片和商家原始链接
- 库存信号和商品成色
- 型号、SKU、GTIN 或变体证据
- 观察时间和来源状态

搜索显示公开商品价；单独提供美国邮编不授权创建购物车。用户明确请求受支持的已选商品报价，并通过宿主一次性匿名 Cart 表单审批后，才可读取配送费、税费和预估总价。未授权、不支持或报价失败保留缺失值；只有核实免费配送才显示 `$0.00`。Woo Cart 报价不在支持范围内。

只有商家返回 `totalTaxAmount` 时，插件才使用 Shopify 税额。否则，商品卡可以显示基于邮编所在州和平均地方税率计算的税费估算。该数字不是结账税额。部分商家需要完整地址或进入结账流程后才返回配送费和税费。不支持 Cart 报价的商家只显示商品价。

后续问题会复用所选结果的 `renderId` 和稳定商品身份。原生 Shopify 卡片使用 Variant ID；受支持的 Awin 商家页面会先把原始商家商品路径安全解析为唯一 Shopify Variant。插件不会重新搜索商品标题，因此商品价、配送费和税费始终对应同一件已选商品。

## 商品卡片

Codex 可以在对话中显示最多 8 张交互式商品卡片：最多 2 张已验证官网卡片、3 张可信精确或相似匹配、3 张高性价比高匹配结果。卡片显示商家信任证据、图片、商家、价格、型号或 SKU、身份信息、变体、商品成色、库存状态、观察时间和商家页面按钮。每张卡片都与生成它的搜索结果或所选变体报价绑定。

如果 Codex 客户端无法显示卡片界面，完整文字结果仍然可用。

## 已验证优惠

Coupon 和促销路径采用失败关闭策略。只有配置的 Deals API 提供当前证据时，插件才会返回 Coupon、Promo Code、会员优惠、Cashback 或线下 Coupon。

缺少证据时，插件会说明优惠来源不可用。它不会虚构优惠码、折扣、到期时间或 Cashback 比例。

默认插件会显示统一商品搜索、商品卡片、证据驱动商品对比、当前优惠查询和 Watch 工具。已归档的 Commerce 平台比价仍然排除；当前对比直接由不可变 FindCheap 搜索快照生成。只有配置完整的服务地址和 Token 后，单独的已验证 Deals 工具才会出现。

## 当前优惠查询

用户选择商品卡片后，优惠查询会继续使用该商品和变体的稳定身份，检查当前商品价、库存、已验证商家优惠候选，以及可用的 ZIP 到手价证据。它不会重新搜索已选商品标题。

价格历史收集和买入或等待预测已停用。商家促销在商家确认该商品适用范围和叠加规则前，只作为优惠候选。

只有用户明确要求提醒或持续监控后，Codex 才会建立定时 Watch。

## 购物监控

用户可以让 Codex 监控商品，并在以下情况发生时通知：

- 价格低于目标值
- 出现已验证 Coupon 或促销
- 商品恢复库存
- 指定尺寸、颜色或变体补货

定时运行和通知由 Codex Automation 完成。只有成功绑定 Automation ID 后，监控才会生效。插件会在 MCP 重启后保留规则、上次观察结果和状态变化，避免对同一结果重复提醒。

价格门槛是严格小于。"低于 $40" 会存储为 `4000` 美分，并在 `$39.99` 触发，不会在 `$40.00` 触发。

暂停、恢复和删除操作会同步 Automation 与 Watch 规则。未验证 Automation 绑定的旧规则会标记为 `LEGACY_UNVERIFIED`，直到完成核对。

示例：

```text
监控 AirPods Pro，已验证商品价低于 $170 时提醒我。
```

```text
这件夹克黑色 M 码补货时提醒我。
```

## 联盟状态

生产环境使用 Awin publisher `3047955` 的私有 Feed List，自动发现所有 `Joined`、美国区、英文 Feed。Railway 服务会在启动时及每六小时下载并验证全部符合条件的 Feed，因此新加入的 Program 不再需要单独添加 Feed URL 或商品品类规则。只有同时包含该 publisher ID 和对应 merchant ID 的联盟链接才会返回，并附带联盟披露。Awin 结果与 Shopify 使用同一套商品卡片；本地开发仍可用 `AWIN_PRODUCT_FEED_PATH` 指定 Feed。

Feed 始终提供商品价、库存和商家商品 ID，但 GTIN、MPN、品牌和 condition 可能缺失。因此结果始终标记为 `DISCOVERY_MATCH`、`DISCOVERY_ONLY`、`condition: UNKNOWN`，不能当作精确同款比价。当原始商家商品路径可安全解析为唯一且受支持的 Shopify Variant 时，后续邮编报价可显示配送费、税费和预估总价；否则继续只显示商品价。优惠券和会员价仍需独立验证。其他来源在没有各自已批准关系时继续使用商家原始链接；佣金不参与排序。

正式部署步骤见 [Awin Product Feed production deployment](docs/product/awin-feed-deployment.md)，包含定时下载、持久化卷、认证接口和所需密钥。

## 安装

### Windows 一键安装

[下载 `Install-FindCheap-Agent.cmd`](https://github.com/yyq8548/FindCheap-Agent/raw/refs/heads/main/installers/windows/Install-FindCheap-Agent.cmd)，双击运行，然后重启 Codex 并创建新任务。安装器会自动添加或更新 marketplace、从 `main` 安装最新版插件，并在需要时配置官方便携版 Node.js 24。它不会索取联盟、商家、支付或账户凭据。

### 手动安装

运行要求：Codex 桌面版或 CLI，以及 Node.js 24。

```powershell
codex plugin marketplace add yyq8548/FindCheap-Agent --ref main
codex plugin add findcheap-agent@findcheap-agent
```

重启 Codex，打开一个新任务，然后尝试：

```text
FindCheap Agent 搜索 DÔEN 连衣裙，显示商品卡片。
```

测试和更新方法请参阅[分享与安装说明](docs/product/findcheap-agent-share-package.md)。

## 仓库结构

- `plugins/findcheap-agent/`：可分发的 Codex 插件。
- `apps/mcp-server/`：本地 MCP 服务器和商品卡片资源。
- `apps/awin-feed-service/`：运行中的 Railway 商品源、注册表和联盟服务。
- `archive/commercial-platform/`：退出活跃构建的 Commerce 与 Ingestion 历史代码。
- `packages/registry-builder/` 和 `scripts/registry-builder.ts`：采集注册表候选、保存证据、执行显式审核，并发布 Railway PostgreSQL 已批准快照。
- `docs/product/`：部署、数据来源、Coupon、Watch 和联盟运行手册。

注册表扩建不会把 Awin 合作关系或技术可访问性自动当成商家信任。操作方法见 [Registry Builder](docs/product/registry-builder.md)。

统一路由使用符合条件的已配置来源；受限 Chrome 恢复遵守服务端资格及宿主授权。目标行为与尚待验收项见 Agent 总设计。

### 可选 WooCommerce 来源

WooCommerce 接入既有 Backend 搜索、图片候选、比较、所选商品检查、优惠和商品价／库存 Watch。Store API 是单店接口，由 FindCheap 维护访问表并聚合。公共商品 GET 不需要注册 WooCommerce 账户或申请平台 API key；各商家的访问限制仍适用。

v0.18.3 源码访问表为 **1,000 个店铺站点：原 200 + 新增 800**，另有 4 家合格储备不进入运行表。新增店铺经过公开美元商品、精确规格、购买页面和美国市场证据核验，只获得搜索访问资格，不自动加入官网、可信零售商或联盟库。公开目录位置用于发现优先级，不证明每家都热门。完整名单见[便携证据](docs/engineering/changes/2026-09-08-woocommerce-expansion-1000-evidence.json)，分母与限制见[数据说明](docs/engineering/changes/2026-09-08-woocommerce-expansion-1000-data.md)。

每轮最多选择 6 家、每次 Backend 搜索最多两轮，不全扫 1,000 家。来源覆盖、库存、价格和地域限制保留；USD 不保证具体地址可配送。商品 URL、父子 ID 和所选属性必须一致；缺失必选规格不能提供确定价格。Woo Cart 和结账仍不支持。

来源服务仅在 `WOOCOMMERCE_SOURCE_ENABLED=true` 时启用。分发插件的 `WOOCOMMERCE_API_BASE_URL` 指向 FindCheap 公共来源服务；独立 MCP 可配置兼容的 HTTPS 地址，也可用 `WOOCOMMERCE_SOURCE_ENABLED=false` 关闭来源。无需结账、账户或管理员凭据。[接入运行手册](docs/product/woocommerce-source-setup.md)记录配置和预算，[v0.18.3 发布记录](docs/releases/v0.18.3.md)分别记录生产与安装缓存状态。
