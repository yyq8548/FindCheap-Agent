## 验证边界

这是**原始对话衍生的离线 MCP 回归**，不是重新运行 Codex 的端到端 prompt 测试。

- 执行真实 MCP 协议、输入校验、搜索编排、卡片数据、优惠评估、引用快照和视觉终审代码。
- 复用当时模型产生的首个工具参数；测试不会重新把中文翻译为搜索词，也不会重新从原图提取特征。
- 商品、价格、优惠、候选图片及终审 verdict 是明确标记的合成样本。供应商不会联网，意外 `fetch` 会使测试失败。
- 历史 `renderId` 只作来源记录；执行时使用测试现场生成的 ID。比较时模拟 UI 勾选，而不是猜用户选了哪两款。
- 报价测试中的 ZIP 是负向接口探针，不是原对话用户提供的数据。无 ZIP 或仅支持结账页报价时，不调用报价工具可能是正确行为，不能仅据此判为失败。
- 图片仅记录附件文件名，不复制个人照片、不依赖临时目录、不把模型猜测的商品名设为视觉正确答案。

通过本套测试，不代表已验证实时库存、当前官网链接、模型选工具的正确率、回复措辞、前端实际渲染或真实看图能力。
