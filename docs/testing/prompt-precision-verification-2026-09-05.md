本文件是发布前开发候选的历史证据。后续授权交付见 [v0.17.21 发布记录](../releases/v0.17.21.md)；本文的版本、哈希和原始实测结果保留，不替换为新发布包的数据。

结论：本轮代码修复及已定义的行为验收通过；三组最终购买目标仍未完成。不能把零错误、正确拒绝不合格推荐等同于完整商品覆盖。

## 独立审查与实测补修

没有只停留在第一次绿色单测：

1. 独立审查复现了新 requiredFeatures 夹带第二身份、借用另一商品的默认造型、从成分/另一款洗发露借用功效。均补反例并修复。
2. 第一轮独立实测发现默认造型仅放 query 时需要参数修正，以及 $1 询价费仍进入预算卡。加入无重复字段的工作流和部分价门槛。
3. 部分价初次补修的措辞样本不够准确，实际商家的 `the quote request fee ... applied toward your final order total` 仍漏过。该次实测判为失败，不计入通过结果；测试改用实测 description 原文，修复后重新构建、运行全量检查及独立原始消息重放。

## 未完成或未声称

- 本轮桥接客户端不支持 elicitation。`PERMISSION_UNAVAILABLE / hostAction=NOT_REQUESTED` 表示测试环境不能发起授权，不是用户拒绝，也不能证明 Codex 桌面弹窗正常或异常。
- 没有验证桌面真实卡片交互、真实授权后的全网补搜、结账税费/运费、优惠券最终适用性或商品独立功效。
- 本轮没有授权扩充可信商家名单；未独立核验商家仍是研究线索，不会因商品描述匹配而自动获得购买推荐。
- 这些是已知开发案例，不是 held-out 样本；没有据此宣称全局 Recall、Precision、图片搜索正确率或全部购物目标达标。
- 来源 COMPLETE 只表示有界调用完成；Awin 查询使用服务当前缓存，不表示本轮刷新了所有上游 Feed，也不是完整全网覆盖。
- 发布、生产环境、已安装 Codex 缓存验证仍需单独授权。
