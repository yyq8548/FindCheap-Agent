# 胶囊搜索修复与 WooCommerce 扩容验收

本页验证本地实现。上线和安装缓存更新是独立步骤；不能用本地构建通过来证明生产环境或当前 Codex 原生宿主已经更新。商家数量以实际访问表和运行回执为准，发现名单、API 预筛和最终准入分别计数。

## 对话测试

在同一购物任务里顺序执行前三句，检查 `goalId` 保持不变、修订号递增。卡片数量与价格可能随上游变化；不要用固定价格代替下面的业务断言。

| 输入 | 必须满足 |
| --- | --- |
| 我要买咖啡 | Awin、Shopify、Woo 分别报告实际执行状态。已识别胶囊的候选不能因用户尚未指定类型而绕过机器兼容性检查。 |
| 胶囊咖啡 | 保留有明确胶囊或 pod 身份的候选；纯菊苣、未烘焙生豆、冲煮头清洁刷、空胶囊不作为胶囊咖啡商品。未知类型只能作为明确标注的研究线索。 |
| 我的机器是 Nespresso Original | 重新评估同一目标下的机器兼容性。不能把 Vertuo、Dolce Gusto 或 K-Cup 当成 Original。旧快照保持不变。 |
| 我要给 Vertuo 用的胶囊，其他系统不要 | 兼容性必须独立匹配；商品明确写“不兼容 Vertuo”时，选中规格不能覆盖这条反证。 |
| 我要咖啡豆，不要胶囊 | 保留整豆约束；不要追问胶囊机器型号，也不要把 K-Cup 研磨选项误认为封装胶囊。 |
| 我要 Nike Air Max 95 BB PRM Greedy 2.0，尺码 14 | 锁定品牌、型号、款式与尺码。Woo 商家接入不自动赋予可信或首选推荐资格；价格和实际库存仍须验证。 |

“没有确认匹配项”只描述已执行搜索的结果。只有部分来源、部分商家或部分页完成时，不得回答“全平台没有这种商品”。

## 覆盖与恢复

1. 检查每个来源的状态与失败原因，区分 `COMPLETE`、`PARTIAL`、未配置和不可用。单个来源的 `COMPLETE` 也只表示对应请求完成。
2. Shopify 存在下一页时，第二轮携带原实际查询和新 cursor；成功读到的新页计入新观测。下一页失败时保留第一页，但失败页新增数量为零。
3. 没有 cursor、没有新查询时，第二轮记录 `NO_INCREMENT`，不把缓存重放当成新增搜索范围。
4. Woo 每次最多选择 6 家，最多两轮；核对累计实际请求商家集合和 HTTP 次数。名单增加到 1,000 家不会把单次查询改成全表扫描。
5. Woo 局部不支持或用尽其预算，不得阻止仍有预算的独立来源恢复。安全拒绝、权限拒绝、输入错误和未知致命错误仍需停止对应不安全路径。
6. 功能要求满足与商品身份匹配分别统计；`SATISFIED` 不能证明未知商品已经匹配目标。
7. Woo 正常达到商品页、变体页或变体数量上限时，每家返回明确的 `boundedReasons`。允许尚有预算的独立恢复，但仍报告覆盖不完整；不得用一家已解释的部分结果覆盖另一家或前一轮原因不明的部分结果。
8. 当前客户端搜索携带 `x-findcheap-woo-coverage: 1` 获取上述元数据；缺失或未知协商值收到旧严格 schema 可接受的字段。新旧请求交替不能修改内部共享结果，原来的部分覆盖、失败原因和预算计数保持不变。

## 新商家抽查

从最终准入证据选取食品、服饰、美妆、家居、电子产品各至少一家。每家使用证据里保存的精确商品和正查询，不预设泛词一定路由到该店。

- 正查询返回真实商品，不可能命中的查询返回空集；HTTP 拒绝、超时和空结果分别记录。
- 精确产品 ID、父子 ID、完整必选属性、币种、价格小数位和落地页一致。
- 通配变体缺少必选维度时可保留发现信息，但不输出确定商品价或确定库存。
- API 明确 `is_purchasable=false` 时，即便 `is_in_stock=true`，也只保留身份，价格和可购买库存保持未知。旧记录未保存该字段不等于已证明可购买。
- 反向不成立：`is_purchasable=true`、`has_options=false` 仍不能证明所有定制项已选。实测店铺可在这两个字段不报警时要求额外设计、口味或表单外规格；新增商家须保留页面审核证据。
- 商品链接中的产品 ID、变体 ID 和规格必须与观察到的商品一致。重复属性若归一化后冲突，不能按最后一个值覆盖；显示名与 taxonomy 的别名必须来自原始父商品证据。
- 带加购、结算、账户操作或未知动作参数的链接，不能进入商品 DTO 和卡片。正常商品地址、受验证的规格参数及 `currency=USD` 保留。
- 商品范围起价不能替代完整选中规格价。多件装、预付多年供货、仅镜架、可选订阅和附加服务不能混成单件完整售价。
- 核实当前公开购买入口；永久隐藏按钮、仅询价、专业账户、批发审批、演示商品和缺失必选定制项不能凭 API 有价而通过。
- 同时检查购买表单外的规格控件；页面辅助投影只是线索。无引号的 HTML 属性、表单外色码选择和动态显示规则需回看原始页面，不能据控件计数自动准入。
- 保留已知地域、提货、预售、最低购买量、状况和费用限制。接入搜索不证明美国所有邮编都可配送。
- 官方明确全球或“欧洲以外其他地区”公开零售配送、且无美国排除时，可证明美国属于其声明服务范围，记录 `OFFICIAL_WORLDWIDE_SHIPPING`。这与地址级结算核验、运费核验及信任资格分开。
- 新增访问资格不自动进入官网库、可信库或首选推荐。
