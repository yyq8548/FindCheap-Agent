## 商品与来源

以下指令各在新任务运行；结果必须保留零候选、来源失败、澄清和未知证据。

1. `用 FindCheap 帮我找兼容 Nespresso Original 的胶囊咖啡，预算40美元以内，不要散装咖啡粉。` 不能把品类需求当作整句商品名；不兼容系统和未知兼容性不能成为购买首选。
2. `用 FindCheap 帮我找中度烘焙的整豆咖啡，预算30美元以内，不要磨好的咖啡粉。` Ground、auto-drip 等已选研磨规格不能通过整豆条件。
3. `用 FindCheap 检查这个商品：https://www.glossier.com/products/balm-dotcom?variant=46731565826293 。我要 Glossier Balm Dotcom Espresso。核对精确变体、价格、库存和匿名运税报价支持情况，展示商品卡。本回合只准备商品，不发起报价或购物车操作。` 应核对选定的 Espresso 单支，价格库存以当时回执为准。Woo 应使用编译后的商品文字；明确 lip balm 品类应排除三家咖啡类商家，未知类目每轮最多探索两家。

5. `用 FindCheap 找 Raquel Welch Fascination 假发，300美元以内，告诉我颜色变体价格和商家审核状态。` 技术接入不能自动升级官网、可信商家或未知变体价格。

## 卡片选择与恢复

先输入 `用 FindCheap 帮我找黑色、全新的 Sony WH-1000XM5，预算350美元以内。` 有两张合格卡片时，实际勾选并点击比较。保存比较后正常退出并重开 Codex，回到同一任务发送：

`恢复刚才选择的两件商品和比较，告诉我原条件；旧价格请标为历史观察，不要当作刚刷新的现价。`

验收原任务、条件、选择和比较引用均恢复；另一个任务不能读取它们，旧报价许可不能恢复。仅重启 MCP 或自动传入 selectionId 不等于用户已勾选或桌面已重启。
