# WooCommerce P13：有限真实来源性能样本

日期：2026-09-08。观察窗口：`16:05:14.656–16:05:18.420 UTC`，本机纽约时间约 `12:05:14–12:05:18`。

本次三次冷聚合耗时 **1.096–1.473 秒**，每次查询三店，总共执行 **9 次真实公开商品 GET**；九次服务缓存命中耗时 **0.080–0.541 毫秒**，没有新增上游请求。测量代码与原始逐次样本均已保存。这些是来源调用段的有限证据，不能证明生产完整搜索的 P95 增量目标已经达成。

## 1. 执行依据与边界

依据用户已批准的[独立来源接入计划](../../product/woocommerce-independent-source-plan-2026-09-08.md) P13，以及本次明确要求补充真实、可复验的性能证据。此前[商家实测](2026-09-08-woocommerce-merchants.md)已验证这些公开接口。

冻结方法：同一进程、同一机器，比较可选来源关闭分支与开启后的实际来源调用段；冷缓存和暖缓存分别记录。选择三家已验证商家，各查询词冷运行一次，再重复三次暖缓存；每次建立新的 `SearchRun`。整次实验至多 12 个真实 GET，超过即在实际传输前拒绝；没有通过增加请求量追求好看的结果。

本次执行链：

```text
计时开始 → 新 SearchRun
  → 关闭：跳过可选来源
  → 开启：SearchRun.read("WOOCOMMERCE")
       → 同进程真实来源聚合器
       → 安全 DNS/IP 校验与 pinned HTTPS GET / 或服务短缓存
       → 来源规范化与预算统计
  → 读取执行统计 → 计时结束
```

测量包含真实出站网络、单店读取、跨店聚合、规范化、服务缓存及 SearchRun 的调度/记账。**没有包括**来源服务入站 HTTP、MCP 薄客户端网络一跳、其他商品源、模型推理、最终排序、卡片渲染或原生 Codex 宿主。关闭分支仅衡量这一段跳过 Woo 的开销；不是关闭 Woo 后整场购物搜索的基线。

未使用假的商品传输响应。计数包装器仍调用原 `createPinnedRequest`，DNS/IP 校验、HTTPS、重定向拒绝、响应大小和取消策略保留。没有登录、凭据、Cookie、购物车、订单、支付或 Automation 操作；没有部署。

## 2. 环境、版本与实际样本分母

| 项目 | 观察值 |
| --- | --- |
| 环境 | 同一 Windows x64 进程，Node `v24.18.0`，Vitest `3.2.7` |
| 当前本地源码版本 | `0.17.35`，未提交工作区；不表示该版本已部署 |
| 基础 Git HEAD | `6fd99b61fa435ac293e173a478b700f87db7d396` |
| 注册表版本 | `2026-09-08`，本实验取其中三店；不是默认五店全集压测 |
| 商家 | Root Science、Burrow Press、Scrub Daddy |
| 固定查询词 | `firm`、`mother`、`original`；每个词均查询三店 |
| 关闭样本 | 计划 12，实际 12；零来源调用 |
| 冷样本 | 计划 3，实际 3；每词一次，9 次真实 GET |
| 暖样本 | 计划 9，实际 9；每词三次，零真实 GET |
| 合计 | 24 个调用段样本；没有删样本、跳过或失败后补分母 |
| 执行上限 | 单 GET 3 秒、单聚合 8 秒、SearchRun 单读 10 秒；沿用整体 active 30 秒/service 90 秒预算 |

“冷”指 FindCheap 来源聚合器的查询缓存未命中，不表示操作系统 DNS、TLS 连接、商家 CDN、WordPress 或数据库缓存都已清空。后两个不同词的冷查询在同一进程运行，可能受这些底层缓存影响；不能称作全链路完全冷启动。

每次测量均使用新的 `SearchRun`，因此九次暖样本的 `searchRunCacheHits` 均为 0，`sourceCacheHits` 均为 1。暖缓存没有更新价格观察时间；同一查询的 `snapshotAt` 与冷样本保持一致。

超时与完成分母：

- 冷上游请求超时：**0/9 GET**。没有重试放大，实际 GET 总数就是 9。
- 冷聚合未完成：**0/3**，三次状态都是 `COMPLETE`，只表示本轮受限计划完成。
- SearchRun 读超时：**0/12 次开启来源调用**。
- 暖缓存上游超时率：不适用，因为没有上游 GET；不能写成新增九次网络成功。
- 本批没有预算超限；所有冷来源调用在聚合 8 秒和 SearchRun 单读 10 秒上限内返回。
