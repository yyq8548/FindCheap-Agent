# v0.18.6 原生操作验收

本清单用于已安装最终候选后的实际 Codex 操作。自动断言、来源读取、缓存哈希和 stdio 进程测试分别记录；不能代替可见卡片选择、桌面重启或用户报价表单。原 medicube 图及 40+40 人工标注仍按用户决定暂缓。

采用独立操作清单并链接现有工程记录，避免把手动验收步骤复制进运行技能。备选是散放在每项修复日志，但用户难以顺序执行。本文无运行产物；以链接、状态和操作边界检查验证。

## 先核对运行版本

新建普通购物任务，实际调用 FindCheap。以原始 MCP 回执的 `findcheap/searchTrace.buildVersion=0.18.6` 为准；不能凭聊天文字、目录名或模型自述确认版本。已有运行任务可能仍使用旧连接，缓存文件相同也不证明其已重载。

## 可以直接粘贴的购物检查

1. `帮我找黑色全新的 Sony 1000XM5，350美元以内。` 应先确认 WH 头戴式或 WF 入耳式，不能提前指定同款首选。
2. 同任务回复：`我要头戴式 WH-1000XM5。` 应保留黑色、全新和350美元预算。
3. `比较符合相同型号、颜色和货况的前两家商家。` 只有真实取得两家同款证据才完成跨店比较；重复的 Condition New 选项不应将同款拆成两个规格。不同颜色、货况矛盾和未知运税仍保留区别。
4. 新任务：`帮我找兼容 Nespresso Original 的胶囊咖啡，40美元以内，不要散装咖啡粉。` 不能当作一个名为整句文字的精确商品；L’OR-only 或 Vertuo-only 不能满足 Original。系统兼容性未知的候选不能成为购买首选。
5. 新任务：`帮我找中度烘焙整豆咖啡，30美元以内，不要磨好的咖啡粉。` 选中的 Ground、auto-drip、french、home-espresso 等研磨规格不能通过整豆条件。
6. 新任务：`找 medicube Zero Pore Pad 原版，70片、155g，不要Mild，比较同规格商家。` FAQ 推荐另一款 Mild 不能直接排除当前商品；缺少当前 SKU 的155g证据仍须标待核验，不能借其他国家条码或运输重量补证。这项不等于暂缓原图已验收。
7. 新任务：`检查 Glossier Balm Dotcom Espresso：https://www.glossier.com/products/balm-dotcom?variant=46731565826293 ，告诉我这个精确变体的价格、库存和报价支持情况。` 应使用当前绑定变体的金额及币种；金额以当时读取为准，不能拿父商品起价或全局货币填补。
8. 新任务：`找 Raquel Welch Fascination 假发，300美元以内，告诉我颜色变体价格和商家审核状态。` Hidden Secrets Wigs 仅新增技术搜索资格，不能自动写成已审核可信商家或原版官网；未知品牌字段、货况或运税不能凭路由标签补齐。

每项保留全部来源失败、零候选、澄清和拒绝。遇权限或安全拒绝按回执结束，不通过另建目标重复申请同一次被拒请求。

## 需要用户实际操作的部分

### 卡片选择及桌面重启

先在有至少两张商品卡的任务中，实际勾选两张卡并点击比较。保存产生的选择／比较回执后，正常退出并重开 Codex，回到同一任务发送：

`恢复刚才选择的两件商品和比较，告诉我原条件；旧价格请标为历史观察，不要当作刚刷新的现价。`

通过条件：原任务身份、要求、选择和比较引用恢复；另一个任务不能读取这些历史；已过期授权不恢复。仅重新运行 MCP 进程的测试结果不替代这一步。

### 报价表单接受、拒绝和取消

先完成 Glossier 精确变体检查并显示可选择卡片。实际任务需要允许交互式审批；Full Access 下自动 DECLINE 只记录宿主限制，不算看见或操作过表单。

在用户确实选择了商品后发送：

`为选中的 Espresso 变体估算寄到测试邮编10001的含运税总价；请显示一次性匿名报价授权表单，不提交订单、不付款。`

用户分别在独立测试场景实际接受、拒绝或取消。每次场景由用户明确开始；拒绝／取消后不自动重试。允许的匿名购物车只用于已审核报价能力，不能索取完整地址、登录或付款资料。需要完整地址或商家能力不足时应停止，并保留未完成原因。

通过条件：接受有真实用户表单回执和一次性许可消费，最终运税有真实结果或明确失败；拒绝／取消不发购物车请求，不暗示可能已创建；旧许可不能复用。
