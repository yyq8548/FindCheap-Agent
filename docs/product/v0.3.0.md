# FindCheap-Agent v0.3.0

v0.3.0 upgrades Shopify results from product discovery to evidence-gated same-product comparison.

## Shipped scope

- Query matching rejects model-prefix false positives.
- Cross-merchant grouping requires exact normalized GTIN and variants, or exact normalized brand,
  MPN/SKU, and variants.
- Matching titles alone never establish same-product identity.
- When a valid group exists, Top 3 contains offers from that group only.
- Without a valid group, results remain `DISCOVERY_ONLY` and cannot be described as like-for-like
  price comparison.
- Explicit same-product requests carry `comparisonMode: SAME_PRODUCT`. Category-only input returns
  `NEEDS_CLARIFICATION` before any merchant or Chrome call.
- Existing condition, availability, relevance, price-ceiling, freshness, and Chrome fallback gates
  remain active.
- Thirty matching evaluations cover the original twenty product-search tasks and ten new
  cross-merchant identity tasks.

## Not shipped

- Shipping, tax, mandatory fees, or delivered price
- Membership pricing
- Coupon verification
- Affiliate approval or attribution
- Checkout, ordering, or payment

Those remain v0.3.1 or later work and require authorized merchant price/context sources.
