# WooCommerce 200 家商家信任审核

审核日期：2026-09-08。全部 200 家有独立结论：**137 家官网 + 可信、45 家可信零售商、18 家仅保留搜索资格**。访问表仍为 `2026-09-08-expanded-200`，数量和六店／两轮预算不变。

这里的“官网”指 FindCheap 内部品牌官网注册表；没有把商家描述成 FindCheap 合作伙伴，也不证明配送、售后结果或联盟关系。可信商家的商品可以参与首选竞争；仍须通过商品身份、规格、价格、库存与用户要求。仅搜索资格不保证展示卡片，产品评分也不能替代商家可信门槛。

## 审核标准与证据

逐家读取公开经营身份、品牌归属、联系及退换／履约／保修支持页面。直营品牌需明确制造、设计、烘焙或出版等自有品牌与域名关系；合格零售商需具体经营主体或持续经营历史，以及实质支持证据。品牌列表、API 可读、联系方式表单或高评分本身不授予信任。

已知混售其他独立品牌的商家归入可信零售商，因为现有官网表按整域映射单品牌。例如 PINE Store、Reily Products、Rug Doctor、Matrix Shad、HiFiBerry 和 Tether Tools 不会把其他品牌商品自动标为自家直营。Model F Labs 仅确认其复刻键盘品牌，不认定为 IBM 官网。

主页技术探测共 **200 次：197 PASS、3 FAIL**。Root Science 与 Miller’s Purely Maple 的去 www 主域探测失败，另行读取的正式 www 身份／支持页面有证据；RECON 返回 403，保留仅搜索。技术失败和页面读取失败均保留，不按审核结论改写。Mountain Laurel Designs、Ojai Jelly 当前明确暂停接单，保留搜索资格；Motodemic 接受订单但发货暂停、Model F 定制交期等限制单独记录。
