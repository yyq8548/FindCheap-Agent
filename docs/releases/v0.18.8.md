# FindCheap Agent v0.18.8

v0.18.8 moves product requirements onto one shared evidence path. It prevents explicit negation, conflicting selected quantities, parent option lists and incomplete compound requirements from producing an eligible primary recommendation. Shopify, Awin and WooCommerce candidates now use the same requirement facts through search, recovery, inspection and comparison.

## Changes

- Supports bounded direct negation, AND/OR and every recognized typed quantity in a requirement.
- Keeps bare numbers and unsupported expressions `UNKNOWN` instead of guessing.
- Prefers selected-variant fields, then the current title and bounded current description; other products and parent option lists cannot establish the selected specification.
- Preserves conflicting selected evidence as `CONFLICT`.
- Uses the same measured evidence for required, excluded and preferred features.
- Adds structured response facts so retained research cards cannot be described as excluded or verified.
- Extracts final snapshot projection and task-state application from the MCP server without changing public tool names or safety boundaries.
- Updates the current architecture and result-language documentation.
