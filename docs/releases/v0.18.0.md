## Scope

WooCommerce joins the existing Backend as an independent catalog source, including category queries in parallel with Awin, Shopify and configured eBay. Exact merchant/product/variant observations support inspection, mixed comparisons, selected deals, visual review and explicitly requested item-price/stock Watch. The source service supplies a bounded five-merchant access registry; Store API itself remains a per-store API. Registry access does not grant merchant trust, affiliate approval or delivery guarantees.

No new dependencies, database migration, checkout or payment capability. Existing Watch data and the old plugin cache are retained; actual Codex host interaction and real Automation acceptance remain separate from SDK/stdio tests.

Enable the reviewed Woo registry, wait for the new deployment, then verify Woo search/lookup/variants/images and source coverage. Do not force Feed refresh or change unrelated credentials/services.
4. Upgrade the existing FindCheap Git marketplace and install its new versioned package. Verify installed/enabled version, source/cache parity, artifact hash and installed stdio. Do not delete or forcibly overwrite a locked older cache; a new versioned cache replaces the active installation.
5. Run bounded read-only tests through the installed bundle and actual production sources; provide repeatable user prompts with observable expectations. Do not create a real Watch or Automation merely to test it.
6. Append independently observed delivery evidence in a documentation-only commit. Documentation changes do not require another runtime deployment or cache replacement.

Rollback uses the prior verified runtime/package and production deployment, freshly identified in preflight. Disable Woo before runtime rollback; reconcile Woo Watch scheduling before downgrading an installation that cannot manage the new file suffix.
