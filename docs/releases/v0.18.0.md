## Scope

WooCommerce joins the existing Backend as an independent catalog source, including category queries in parallel with Awin, Shopify and configured eBay. Exact merchant/product/variant observations support inspection, mixed comparisons, selected deals, visual review and explicitly requested item-price/stock Watch. The source service supplies a bounded five-merchant access registry; Store API itself remains a per-store API. Registry access does not grant merchant trust, affiliate approval or delivery guarantees.

No new dependencies, database migration, checkout or payment capability. Existing Watch data and the old plugin cache are retained; actual Codex host interaction and real Automation acceptance remain separate from SDK/stdio tests.
