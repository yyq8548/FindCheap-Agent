# FindCheap Agent v0.17.18

## Text-search reliability

- Read variant-specific USD prices from both `ProductGroup` and `Product` JSON-LD
  offers. Never substitute another variant's price or an aggregate minimum.
- Apply explicit colors and sizes before choosing an official variant. Compound
  and Chinese color names use selected-variant evidence, not other advertised colors.
- Preserve the full named product through bounded official query fallback. Start
  explicit-brand official retrieval alongside other sources and skip redundant
  official stages once a qualifying exact result exists.
- Treat a stated budget as an inclusive ceiling. Missing or non-USD prices cannot
  satisfy a USD budget, and research-only candidates do not end replenishment early.
- Remove obsolete intermediate Catalog questions from final text results.

## Verification and limits

- Added 18 regression cases and one configuration-with-budget case. The complete
  suite passes 960 tests across 73 files, including existing visual and stdio tests.
- Typecheck, lint, MCP build and whitespace checks pass.
- Versioned MCP bundle SHA-256:
  `af34ea4ca5820383e8ae3f1220f89aa06fe44cb1e8f84844c415fa078f60ec15`.
- A read-only live probe recovered the exact Margaux US 7 variants' USD 325 prices.
  Those results remain research-only where independent merchant evidence is missing.
- SKIMS Heather Grey retrieval still has a coverage gap. This release does not
  claim every text query succeeds or that an unreturned product is unavailable.
- Image-review flow, merchant trust, identity checks, immutable selections and
  read-only boundaries remain unchanged. See [the test report](../testing/text-search-reliability.md).

## Delivery scope

This release covers GitHub source and the local Codex plugin. No manual Railway
deployment, registry publication, database migration or new product index is needed
for these MCP text-search changes. Installation and remote checks are verified
separately after publishing. Rollback target: v0.17.17, commit
`ff1bbd795d309b9bf03c09964fee5679b7d7518d`.
