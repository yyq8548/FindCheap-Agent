# FindCheap v0.18.3

Released **2026-09-09 UTC**. This patch expands WooCommerce discovery to 1,000 configured storefronts and repairs capsule matching, pagination, coverage reporting and bounded recovery. Production deployment, installed-cache verification and the [GitHub Release](https://github.com/yyq8548/FindCheap-Agent/releases/tag/v0.18.3) are complete.

Package: `0.18.3+codex.20260909031910`. Product-card resources advance to `v44`; comparison resources advance to `v14`. Existing running Codex processes need a reload to use the new package.

## What changes

- **More Woo stores, with the same request budget.** The source registry `2026-09-09-expanded-1000` contains the unchanged original 200 stores plus 800 new search-only admissions. Four qualified reserves stay outside runtime. Each addition has actual public USD product, exact selection, public-sale and US-market evidence. Public directory positions guide discovery priority; they do not prove every store is popular. See the [data summary](../engineering/changes/2026-09-08-woocommerce-expansion-1000-data.md) and [complete portable evidence](../engineering/changes/2026-09-08-woocommerce-expansion-1000-evidence.json).
- **Capsules stay distinct from equipment and incompatible systems.** Coffee clarification keeps the original goal and requirements. Capsule form and machine compatibility are assessed separately, including actual roast/brew single-serve-cup titles without the word coffee. Brushes, empty capsules, conflicting grounds and unrelated foods do not become capsule matches. Unknown machine compatibility prompts clarification and prevents a primary recommendation; K-Cup does not imply Nespresso Original compatibility.
- **A second pass can retrieve new evidence.** Shopify uses a query-bound next-page cursor when available. Repeated queries without a new page or useful query change report no increment. Coverage counts actual pages, stores and requests across passes; estimated source totals are not counts searched.
- **Partial Woo coverage no longer blocks every recovery path.** Explained store limits and unsupported-store responses allow otherwise eligible independent recovery within the existing budget. Security, permission and fatal failures remain enforced. Browser recovery still requires a server-issued action and host authorization.
- **Exact Woo prices and links stay bound to the selection.** Conflicting product/variant URL parameters and duplicate normalized attributes are rejected. Incomplete required choices and explicitly non-purchasable products retain discovery identity without a confirmed price or availability. Links containing cart, checkout, account or unsupported action parameters cannot become product-card URLs.
- **Older clients retain their response shape.** New clients opt into Woo coverage details with `x-findcheap-woo-coverage: 1`. Missing or unknown capability values keep the legacy strict store shape without changing the shared internal result.

No merchant-trust database change is included. The [prior 200-store trust review](../product/woocommerce-merchant-trust-200.md) remains separate from the larger access registry. Ratings and source admission do not grant merchant trust or primary recommendation status. No Woo Cart, checkout, order or payment support is added.

## Try after installation

Restart Codex and open a **new task** after cache verification. In one task, ask “我要买咖啡”, then “胶囊咖啡”, then “我的机器是 Nespresso Original”. The goal should continue, old cards should remain unchanged, and incompatible systems must not become confirmed offers. Missing compatible results or incomplete coverage must remain explicit.

Use the [repeatable acceptance tests](../testing/capsule-search-and-woocommerce-expansion.md) for source coverage, selected variants and real-store checks. Current inventory and results can change. Woo searches select at most six stores per pass and at most two passes; neither a successful response nor an empty result surveys all 1,000 stores. Market evidence does not guarantee every US address, shipping cost, stock or delivery date.
