# FindCheap Agent v0.17.17

## Requirements, variants and comparisons

- Preserve prior requirements on budget/constraint follow-ups using an explicit,
  unexpired parent snapshot. Withdrawn constraints must be explicitly cleared;
  no process-global latest search or silent selection remapping.
- Distinguish required shoe sizes from display sizes. Require source evidence
  for US/UK/EU sizing; never infer a size system from country or currency.
- Assess hair length/texture and selected-variant evidence. Conflicts are
  excluded; missing evidence remains separately labeled research, not a match.
- Inspect at most four exact products with concurrency two in the existing
  search budget. Keep price, currency, identity, link and image variant-bound.
- Negotiate backward-compatible Awin requirement filtering before top-N. Reuse
  the resident search text with bounded public evidence; no second feed index.
- Show the official tier only for a requested brand. Manually verified approved
  Awin merchants retain trust; ratings alone never certify a merchant.
- Cards and comparisons share requirements and variant evidence. An explicit
  variant update creates a new complete snapshot; old references are unchanged.

## Safety

- Normalize and fence external evidence before its output-length cap. Strict
  output validation remains; diagnostics include schema paths/reason codes only.
- Preserve host/identity checks, shared budgets, coupon applicability, quoted
  totals, immutable selections and read-only scope. No purchase or checkout.
- No persistent local product directory, background catalog importer or new
  merchant approval. Existing storefront/trust registries and Watch remain.
