- Match color requirements against the selected variant. Shared descriptions and photographed colors cannot establish a different variant's color. Missing evidence remains unknown; positive, excluded and preferred colors follow the same boundary.
- Share static quote eligibility between snapshot cards and execution. Unverified or unsupported targets are not advertised as quoteable; execution still revalidates the exact variant, merchant and safe URL, and requires real form-bound one-use authorization.
- Return snapshot-bound single-quote operation receipts, including selection provenance, even when consent fails after a valid selection. Invalid or foreign references do not acquire validated-target receipts.
- Render exactly nine comparison rows in both views: product, specifications, comparison price, item price, quality evidence, delivered total, offers, condition and merchant trust. Stock, unit price, requirement conflicts and supported visual differences remain visible within the relevant rows. Update UI resource keys to cards v35 and comparison v5.
- Localize Coupon success and failure receipts using the current requested language. Preserve source facts, merchant names and Coupon codes. Coupon research never creates a Cart, including when a ZIP is available.

No new runtime dependency, source trust grant, arbitrary network access, local product catalog, Watch scheduler, persistence migration or authorization bypass. No fabricated discount, delivered total or commission-based ranking.

## Remaining acceptance limits

The desktop host's immediate DECLINE without a visible popup remains unresolved. Refusal stops quote execution; this release does not retry blindly or bypass host consent. Real desktop authorization, actual merchant Cart side effects and final model wording need separate acceptance. Browser previews and automated fixtures do not establish real-host or independent image accuracy.

Task-scoped restart memory and archive/delete integration, actual Watch scheduler binding/stop/notifications, whole-turn timing and independent image acceptance remain overall design gaps. Restart Codex and open a new task to load the updated MCP and skills; cache replacement cannot hot-reload running processes.
