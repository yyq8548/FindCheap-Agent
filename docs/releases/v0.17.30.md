## Release decision and frozen plan

Chris explicitly authorized commit, push, deployment, installed-cache replacement
and replay of the test report. Research: local and remote main were
`0f2368ae3dd429a6633328d2232057e3afe9b695`, installed/enabled package was

No dependency, database, credential, shopping-history or Watch policy change.

Options: A, retain 0.17.29 and distinguish artifacts by package suffix/hash; B,
publish patch version 0.17.30 with a separate versioned cache. Choose B for clear
runtime and rollback identity. Neither option requires overwriting a locked cache.

Frozen order: synchronize versions and release notes; build MCP/Awin artifacts;
run typecheck, lint, full default suite, stdio and diff checks; commit/push and
verify CI; deploy only existing Railway FindCheap-Agent/production; verify health,
readiness, deployed artifact and read-only source search; upgrade the configured
marketplace; verify enabled installed package and source/cache hashes; replay the
three frozen development cases through that installed bundle. The diagnostic
script gains only the existing stdio-test FINDCHEAP_PLUGIN_ROOT override so the
report is bound to the installed artifact. No production database tests or writes.

Rollback target: v0.17.29 runtime commit
`580dc9b7fcc3885c5f7515c78742eb44aa510e20` and retained versioned cache.
Readiness or identity/authorization regressions block rollout. Transient upstream
failures retain valid source snapshots. A running Codex session is not assumed to
hot-switch when its installed version changes.

## Changes and safety

- Measurements such as 155g are not model identifiers. Request-name/edition
  confirmation and stable cross-merchant same-product identity are separate.
- Unrequested Mild editions remain research-only; explicit Mild is usable when
  its other evidence qualifies. Shared Catalog identifiers do not prove request identity.
- Proven equivalent merchant/variant offers produce one card. Original immutable
  references and complete source observations remain; price and stock are not spliced.
- Final cards own merchant/offer counts, recommendation and recovery explanation.
  Incomplete comparison does not falsely claim that no product was found.
- Typed brand/MPN evidence survives comparison; conflicting MPNs fail closed.
  Selection, quote consent, trust, URL validation and visual-review boundaries remain.
