# FindCheap Agent v0.18.7

This patch corrects how a recognized Shopify product link enters WooCommerce search. The official Shopify reader can establish product and variant identity, while WooCommerce receives compiled product text. Previously the foreign Shopify URL was also sent as a Woo direct-product target, causing a source rejection before merchant selection.

After the R1 native regression, the user approved an additional category-priority rule: an explicit product category excludes merchants whose recorded categories clearly conflict; absent or ambiguous category metadata retains bounded exploration. Flavor or color words in the query cannot override the product category. R2 implements this rule and forwards an existing validated visual product type when no top-level type is supplied. The original NF07 proposal to suppress all zero-relevance exploration remains separate and unanswered.

Existing private Woo anchors retain priority. Known Woo links keep direct reads, and unresolved links keep their existing registry-bound checks. The Woo backend security checks, merchant exploration budget, trust rules and exact-product qualification remain unchanged.
