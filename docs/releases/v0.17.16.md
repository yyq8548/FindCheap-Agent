# FindCheap Agent v0.17.16

## Real-time product retrieval

- Remove the persistent local official-product directory, keyword cache, sitemap
  inventory, import/refresh command, and local ranking/merge path.
- Keep reviewed official-storefront and trusted-merchant registries. Product
  retrieval continues through live official, Awin, Shopify and configured eBay
  providers; the remote Awin feed index is not removed.
- Existing local directory files are ignored, not deleted. Same-search bounded
  memory reuse, immutable card/selection snapshots and authorized Watches remain.

## Visual retrieval and security

- Continue untried official queries after failed visual review; previously reviewed
  text matches cannot stop the continuation again.
- Keep two second-round slots for remaining same-search candidates and reserve
  one for fresh official retrieval when appropriate. No new review round or
  increased total budget.
- Preserve the original effective Shopify query and add a separate structural
  query. Exclude swimwear, bodysuit and jumpsuit/romper family mismatches.
- Count actual HTTP dispatches, consumed body bytes and document-cache hits
  separately. Enforce transport bounds and same-host canonical/variant proof.
- Identity, trusted merchants, pricing, read-only scope and visual review remain
  fail closed. No new host approval, checkout, purchase, or background crawl.
