## Changes

- Recover missing required brand from the identity-bound merchant document before the final gate, within the existing four-inspection/two-concurrency budget. Conflicting or absent brand evidence remains insufficient.
- Omit malformed optional Catalog prose without dropping a valid offer. Identity, price, condition, URL, response size and transport validation remain strict; no misleading prefix truncation.
- Preserve an explicitly supplied condition constraint when the compact query omits the condition word. Missing condition still defaults to ANY; unknown condition does not satisfy NEW.
- Lock the original variant during brand-only enrichment. A genuine sibling change cannot inherit its old price, image or NEW status; structured condition evidence is checked independently.
- Add a fixed, credential-free, read-only Sony official adapter to the existing official-source port. Bind model, exact color SKU, canonical URL, selected variant, USD price and stock to official source evidence. Request/byte/concurrency limits, cancellation and redirect rejection remain enforced. This uses the already reviewed Sony merchant record, not a wider trust policy.
- Explain host authorization refusal without claiming that a popup appeared or that the user clicked Reject. This does not repair or bypass desktop host permission policy.

No new shopping tool, generic proxy, local product directory, new runtime dependency, cart call, real Watch, global permission change or database migration is included. Sony's reviewed product-condition policy is source-specific and does not infer product condition from merchant trust.

## Remaining acceptance limits

The original host's 2 ms decline without a visible popup is not proven fixed. A failed host authorization must still block webpage recovery; it is not evidence that the product does not exist. Successful direct Sony retrieval is a separate path, not consent bypass.

Existing design gaps remain: trusted task-scoped restart memory and archive/delete events; actual scheduler binding/stop/notification delivery; unattended Watch source admission; real desktop quote consent; whole-turn 90/180-second timing and P95; at least 40 frozen independent image samples. No new general image-accuracy or whole-design-completion claim is made.
