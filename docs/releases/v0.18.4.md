# FindCheap Agent v0.18.4

This release repairs task recovery, product identity, source diagnostics and Watch persistence. It does not declare every business or native-host acceptance case passed.

## Changes

- Trusted Codex task metadata isolates shopping requirements, selections and comparisons. A local SQLite store restores original references after restart; historical facts retain their timestamps and expired permissions stay expired. Added `get_shopping_history` and explicit current-task `clear_shopping_history`.
- Revision checks and deletion tombstones prevent stale writers from restoring erased history. New task Watch directories use crash-released transaction locks and atomic JSON/CAS saves. Confirmed archive pauses local Watch work; unknown host state blocks new/executing task-bound watches, and unarchive never resumes them automatically.
- Restock completion atomically saves its stable event and original notification payload. Repeated checks return the same historical event without rechecking stock or issuing another trigger. Delivery remains unconfirmed until a real host receipt exists.
- Bare Sony XM5/XM6 families require WH/WF clarification. Refinement preserves the original goal and budget. Selected coffee-form aliases override conflicting shared titles. Quote eligibility, batch errors, UI outcomes and final match/research counts are consistent.
- WooCommerce routes relevant stores first and limits unrelated exploration to two per round. Negotiated diagnostics distinguish content type, JSON syntax, schema, variant binding and resource limits while preserving failed store-round denominators.
- Registry `2026-09-09-priority-1002` adds Recool Hair and Silent Sound System as research-only sources. Verified extra-option pricing makes price/stock UNKNOWN; neither merchant gains official/trusted status or exact-price/stock eligibility.

## Compatibility and limits

Pre-v0.18.4 Watch records without trusted task ownership are preserved in the original directory. A new task-bound connection cannot claim them by ID. Their host schedules are not automatically stopped or migrated; verified ownership reconciliation is required. Avoid duplicate schedules. Non-Codex legacy clients retain their earlier local behavior.

Storage lives below `FINDCHEAP_STATE_DIR` (default `~/.findcheap-agent/watches-v1`): `shopping-state-v1.sqlite` and `task-watches-v1/<task-id>`. History has a 30-day retention window, 8 MiB/task and a 500-record ceiling including revision tombstones. It excludes chat transcripts, raw reference images and authorization tokens. Explicit clearing does not stop Watch schedules. Missing host metadata is not reliable proof of task deletion, so automatic deletion cleanup is not claimed.

Original medicube image and 40-business/40-image labeled acceptance sets are deferred by the user. Same-SKU medicube/Sony cross-store acceptance, actual host quote approval, notification delivery/stop ACK and complete-turn P95 remain open. A native-model search was blocked by `approval policy is never`; no substitute approval is counted. Two added Woo merchants do not establish mainstream Sony coverage.
