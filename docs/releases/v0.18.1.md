# FindCheap v0.18.1

The 200-store Woo access registry now has individually reviewed trust dispositions: **137 official brand stores, 45 established retailers and 18 stores retaining search access only**. Approved records are separate from access permission. Eligible Woo offers compete through the existing product, variant, stock, price and merchant gates; merchant approval alone never creates a primary recommendation.

Woo official URLs and brands use the existing Backend Woo catalog, with reviewed-host priority inside the same six-store/two-pass budget. Explicit product brands are preserved. Known mixed-brand merchants receive retailer status to avoid applying one brand to every product on their host. Old clients negotiate the supported official-registry subset; the full representation requires schema 2 and has an independent ETag. Both UI resources advance their cache identifiers because their embedded runtime version changes.

The [200-store review](../product/woocommerce-merchant-trust-200.md) links every merchant, decisive evidence and limitations. The [portable ledger](../engineering/changes/2026-09-08-woocommerce-trust-200-evidence.json) retains unsuccessful reads and all 200 technical probes: 197 PASS / 3 FAIL. The [explicit approval payload](../../config/registries/reviewed-woocommerce-trust-2026-09-08.json) contains 319 records: 137 official plus 182 trusted. Existing 111 official and 211 trusted records are preserved; the intended published totals are 248 and 393.
